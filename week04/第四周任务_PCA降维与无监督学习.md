# 第四周任务：PCA 降维与 K-means 聚类

## 一、本周目标

1. 理解 PCA 怎样把多个特征组合成较少的新特征，认识主成分、解释方差和重构误差。
2. 在同一份回归数据上比较降维前后的预测结果，继续练习只在训练集拟合预处理、用验证集选择配置、用测试集评价结果。
3. 实际运行 K-means，比较两组聚类配置，结合轮廓系数、特征统计和可视化解释分组结果，理解聚类与真实类别的区别。

这周继续使用之前的数据、环境和 GitHub 仓库。大家已经比较熟悉 Codex 辅助编程了，**本周安排两项实践：PCA 回归对照和 K-means 聚类。** 两项实践共用数据和预处理结果，预计需要约 4–5 小时，其中聚类部分约 60–90 分钟。使用 Codex 时，也要留意它生成的代码在做什么，能结合自己的结果解释关键步骤。

## 二、知识点理解

| 知识点 | 需要理解的问题 |
|---|---|
| PCA 与主成分 | 从 10 个特征变成 2 个主成分，是直接挑出原来的两列吗？主成分怎样由原特征组合而成？ |
| 投影与降维 | 可以把投影理解成怎样换一组坐标描述样本？减少的是每条样本的特征数，还是样本数？ |
| 特征尺度 | 为什么本周先标准化再做 PCA？数值范围大的特征会怎样影响方差和方向选择？ |
| 解释方差 | 单个主成分的解释方差比例、多个主成分的累计比例分别表示什么？它们是预测准确率吗？ |
| 重构误差 | 从少量主成分近似恢复输入，为什么通常不能完全还原？重构误差与预测目标的误差有什么区别？ |
| 无监督学习 | PCA 拟合方向时使用输入 `X`，是否需要回归标签 `y`？后面的线性回归为什么仍是监督学习？ |
| 预测信息与配置选择 | 保留更多输入方差是否保证预测更好？本周为什么依据验证 RMSE 选择主成分数量？ |
| K-means 与聚类 | K-means 怎样按距离分组和更新中心？`K` 表示什么？聚类编号能直接解释为正常或异常吗？ |
| 聚类评价与可视化 | 轮廓系数关注组内与组间的什么关系？在 10 维空间聚类，再画成二维，为什么图上可能有重叠？ |

PCA 的主成分是原特征的线性组合。可以把二维数据想成平面上的一团点：用沿点云主要延伸方向的一条轴描述它们，就是一个投影例子；只留下这一条轴上的坐标，会丢掉另一方向的信息。学习时先从这个几何图像入手，理解主成分是怎样形成的。参见 [PCA 概念说明](https://scikit-learn.org/stable/modules/decomposition.html#pca)。

本周先按列标准化，再调用 PCA。scikit-learn 的 `PCA` 会中心化输入，各列的标准差缩放则由前面的 `StandardScaler` 完成。调用和属性可核对 [PCA 官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html)。

## 三、实践任务

### 实践一：PCA 前后的线性回归对照

继续通过 `load_diabetes(as_frame=True, scaled=False)` 读取数据，输入使用全部 10 个特征，预测目标为 `target`。

可以从第三周的代码开始，复用数据划分、指标计算和绘图部分，将本周代码放在新的 `week04` 文件夹中。

1. **划分数据。** 沿用约 60% 训练、20% 验证、20% 测试的划分方式，固定随机种子，例如 `42`。所有模型共用这份划分，在本周脚本中一起运行，方便比较。
2. **只在训练集拟合标准化。** 用 `StandardScaler` 在训练特征上 `fit`，再对训练、验证和测试特征 `transform`。目标值保持原样。三部分使用相同特征顺序和同一套统计量。
3. **拟合 PCA。** 分别建立 `n_components = 2` 和 `n_components = 5` 两个 PCA，设置 `svd_solver="full"`、`whiten=False`，在标准化后的训练特征上拟合，再用各自的 `transform` 处理训练、验证和测试特征。这样三部分数据使用的是训练集学到的同一组投影方向。相关原因可参考 [预处理与数据泄漏说明](https://scikit-learn.org/stable/common_pitfalls.html#data-leakage)。
4. **训练下表中的四组模型。** PCA 后的回归输入是主成分坐标，标签仍为对应训练样本的 `target`。除了是否降维及保留的维数，保持回归算法、样本划分和指标一致。

   | 模型 | 输入与设置 | 比较目的 |
   |---|---|---|
   | 均值基线 | 始终预测训练集目标均值 | 保留不利用特征的参考水平 |
   | 未降维线性回归 | 标准化后的全部 10 个特征，`LinearRegression` | 作为降维前的对照 |
   | PCA 2 维 + 线性回归 | 前 2 个主成分，`LinearRegression` | 观察较强压缩的影响 |
   | PCA 5 维 + 线性回归 | 前 5 个主成分，`LinearRegression` | 观察保留更多主成分的影响 |

5. **比较预测结果并选配置。** 输出四组模型的训练、验证 MAE 和 RMSE，画一张训练与验证 RMSE 分组柱状图。依据**验证 RMSE**在两组 PCA 回归中选择维数；若相同，选 2 维。选定后，使用已经训练好的均值基线、未降维线性回归和选定的 PCA 回归计算测试 MAE、RMSE，写入同一份指标表，另一组 PCA 的测试列留空。测试结果用来评价这次选择，维数的选择依据仍是验证结果。
6. **观察保留了多少输入变化。** 对两个 PCA 分别求 `explained_variance_ratio_` 的和，记录保留 2 维、5 维时的累计解释方差比例。为了看清完整趋势，再在同一份标准化训练特征上拟合一个保留全部 10 个主成分的 PCA，设置仍为 `svd_solver="full"`、`whiten=False`。用它绘制从 1 到 10 维的累计解释方差曲线，并标出 2 维和 5 维的位置。
7. **检查重构误差。** 对两个降维 PCA，分别用训练、验证主成分坐标调用 `inverse_transform`，近似恢复各自的 10 维输入。将恢复值与对应的**标准化特征**比较，计算下面的重构 MSE，与累计解释方差比例一起保存到 PCA 信息表。

   ```text
   X_scaled：标准化后的输入特征，形状为（样本数，10）
   Z = pca.transform(X_scaled)
   X_reconstructed = pca.inverse_transform(Z)
   重构 MSE = mean((X_scaled - X_reconstructed)²)
   ```

   这里 `mean` 对全部样本、全部 10 列的平方差取平均。PCA 接收的是标准化输入，恢复值也在标准化特征空间，因此计算误差时，两边都使用标准化后的数值。
8. **结合自己的结果解释。** 看看 2 维和 5 维保留的方差、重构误差有什么差别，以及降维前后的回归表现怎样。组会时结合图表说明自己为什么选择这一维数。PCA 可能改善预测，也可能损失有用信息，按实际结果讨论即可。

实践一的结果包括**两份 CSV 表、两张 PNG 图**，由 Python 脚本生成，放在 `week04/results/` 中：

| 结果 | 最少包含的内容 |
|---|---|
| 指标比较表，如 `metrics.csv` | 模型、PCA 维数（不适用时可留空）、训练/验证 MAE 与 RMSE、规定模型的测试 MAE 与 RMSE、选定配置标记 |
| PCA 信息表，如 `pca_summary.csv` | 2 维和 5 维各一行；维数、累计解释方差比例、训练重构 MSE、验证重构 MSE |
| 预测误差对比图，如 `rmse_comparison.png` | 四组模型的训练与验证 RMSE；图例和模型名称明确 |
| 累计解释方差图，如 `pca_variance.png` | 横轴为保留维数 1–10，纵轴为训练数据的累计解释方差比例；标出 2 维、5 维 |

解释方差和重构误差帮助我们了解 PCA 保留了多少输入信息，回归 MAE、RMSE 则反映目标预测得怎样。可以把两份表放在一起看：保留更多输入方差时，预测是否也更好了？

### 实践二：实际运行 K-means 并解释分组结果

接下来，用实践一的训练样本和标准化后的全部 10 个特征做聚类，看看这批样本能形成怎样的分组。

K-means 的基本过程是：先设定组数与初始中心，按距离把样本分给较近的中心，再用组内样本的均值更新中心，交替进行直到基本稳定。可以结合 [K-means 概念说明](https://scikit-learn.org/stable/modules/clustering.html#k-means) 理解，再用下面的步骤运行实验。

1. **准备输入。** 使用 `X_train_scaled` 的 10 列特征，让 K-means 根据输入的相似性分组。这里用到的是特征数据，`target` 留在前面的回归任务中。
2. **训练两组配置。** 分别调用 `KMeans(n_clusters=2, random_state=42, n_init=10)` 和 `KMeans(n_clusters=3, random_state=42, n_init=10)`，在同一份 10 维标准化训练特征上独立拟合。取得各自的 `labels_` 和 `cluster_centers_`。`n_clusters` 指定分组数量，`n_init=10` 会让程序尝试 10 次初始化并保留其中目标较好的一次。参数可核对 [KMeans 官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.cluster.KMeans.html)。
3. **计算轮廓系数。** 分别使用 `silhouette_score(X_train_scaled, labels, metric="euclidean")`，比较两组结果。轮廓系数衡量组内紧密程度与组间分离程度，通常越高表示当前距离定义下分组越清楚。它评价的是分组结构，与有真实标签时的分类准确率含义不同。参见 [轮廓系数官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.silhouette_score.html)。
4. **查看各组包含什么样的样本。** 对 K=2、K=3 分别统计每个组的样本数，以及组内原始 `bmi`、`bp` 的均值。将 `labels_` 与未标准化训练数据按相同行顺序对应起来，并核对各组样本数之和是否等于训练样本总数。这两个熟悉的特征可以帮助我们描述各组的差别。
5. **画一张双面板聚类图。** 横轴为 PC1，纵轴为 PC2，复用实践一已经拟合的 2 维 PCA 对训练特征的投影。左图按 K=2 的组号着色，右图按 K=3 的组号着色；两图使用相同样本坐标、坐标范围，并标出各组中心。中心原本在 10 维标准化空间，也要用同一个 PCA 的 `transform(cluster_centers_)` 投影到二维后绘制。
6. **结合实际结果解释。** 比较两组配置的轮廓系数、各组样本数和特征均值，看看增加一个组以后发生了什么变化。图上的分界可能清楚，也可能有不少重叠，可以联系“10 维聚类、二维展示”来理解。组号只是标记，若想进一步解释各组的实际含义，还需要查看样本和相关背景。

实践二的结果包括**两份 CSV 表、一张 PNG 图**，同样放在 `week04/results/`：

| 结果 | 最少包含的内容 |
|---|---|
| 聚类指标表，如 `cluster_metrics.csv` | K=2、K=3 各一行；K、轮廓系数、随机种子、`n_init`、拟合使用的特征维数 |
| 组内统计表，如 `cluster_summary.csv` | 每个 K 下每组各一行；K、组号、样本数、原始 `bmi` 均值、原始 `bp` 均值 |
| 聚类对照图，如 `cluster_comparison.png` | K=2 与 K=3 双面板；PC1、PC2 坐标、组号图例和投影后的中心；注明“10 维聚类，2 维展示” |
