## 二、知识点理解

| 知识点 | 需要理解的问题 |
|---|---|
| 多特征线性回归 | `预测值 = w1 × x1 + w2 × x2 + … + b` 表示什么？增加的是输入特征还是预测目标？为什么仍叫线性模型？ |
| 标准化与权重 | 多个特征怎样分别标准化？为什么各列使用自己的训练集均值和标准差？不同单位下的权重能直接比较吗？ |
| 欠拟合与过拟合 | 训练和验证表现都差，或者训练好而验证差，分别提示什么？为什么增加特征不保证新数据上的效果更好？ |
| 正则化与 Ridge | 在拟合误差之外约束权重有什么作用？`alpha` 增大意味着什么？它与第二周的学习率有什么区别？ |
| 公平对照与方案选择 | 比较模型时，为什么要固定样本划分、预处理和评价指标？为什么根据验证结果选择 `alpha`？ |
| 逻辑回归与分类概率 | 逻辑回归为什么用于分类？“属于类别 1 的概率估计”为 0.8，与“预测类别为 1”有什么区别？ |
| 分类评价 | 准确率、精确率、召回率分别关注什么？F1 怎样综合精确率和召回率？类别不均衡时为什么只看准确率可能不够？ |

本周正则化以 **L2 与 Ridge** 为重点。L1 只需知道它使用权重绝对值之和作为惩罚，可能使部分权重变成零；L2 使用权重平方和，倾向于缩小权重整体规模。暂不要求实现 Lasso，也不要求推导解析解或矩阵求导。

Ridge 的基本思想是同时考虑“拟合误差”和“权重大小”。scikit-learn 的 `Ridge` 使用以下目标，默认拟合的截距不计入这里的权重惩罚：

```text
目标 = 所有训练样本的平方误差之和 + alpha × 所有特征权重的平方和
```

注意这里是**平方误差之和**，与第二周的 MSE 相差样本数这一因子。若改用平均误差，惩罚项系数也要相应换算，不能直接照搬同一个数值。理解两部分分别起什么作用即可，不要求自行编写 Ridge 求解器。参见 [Ridge 官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html)。

### 实践一：多特征线性回归与 Ridge 对照

继续通过 `load_diabetes(as_frame=True, scaled=False)` 读取数据。目标仍为原来的 `target`，本周将输入从 `bmi` 扩展为数据集提供的全部 10 个特征。**不能把 `target` 放进输入特征，也不要把表格行号当作时间。**

1. **固定数据划分。** 沿用第二周约 60% 训练、20% 验证、20% 测试的划分方式。对样本行一次性划分，再从相同样本中分别取 `bmi` 或全部特征。固定随机种子；如果要直接引用第二周的指标，还应确认样本顺序、两次划分的设置和样本归属确实相同。也可以在本周脚本内重新运行单特征对照，避免跨文件核对。
2. **按列标准化。** 只在训练特征上计算各列的均值和标准差，再用同一组统计量处理验证和测试特征。可以复用 NumPy 实现，也可以使用 `StandardScaler`；目标值保持原样。单特征模型使用标准化后的 `bmi` 列，多特征模型使用全部标准化特征。
3. **训练下表中的模型。** 所有模型使用同一组训练样本。Ridge 只比较 `alpha = 1` 和 `alpha = 100` 两个设置；两者都从训练数据独立拟合。（这里改变的是正则化强度，不是梯度下降步长。我会提问！这个概念弄清楚。）

   | 模型 | 输入与设置 | 比较目的 |
   |---|---|---|
   | 均值基线 | 始终预测训练集目标均值 | 保留不利用特征的参考水平 |
   | 单特征线性回归 | `bmi`，使用 `LinearRegression` | 与第二周衔接，观察增加特征的影响 |
   | 多特征线性回归 | 全部 10 个特征，使用 `LinearRegression` | 作为不加正则化的对照 |
   | Ridge，`alpha = 1` | 全部 10 个特征 | 较弱正则化设置 |
   | Ridge，`alpha = 100` | 全部 10 个特征 | 较强正则化设置 |

4. **比较训练和验证结果。** 输出五组模型的训练、验证 MAE 和 RMSE，并画一张训练与验证 RMSE 的分组柱状图。依据**验证 RMSE**在两组 Ridge 中选定一个 `alpha`；若相同，可固定选较小值。然后对均值基线、单特征线性回归、多特征线性回归和选定的 Ridge 计算测试 MAE、RMSE。本周直接评价已训练的模型，不增加合并训练集与验证集后重训的步骤，也不根据测试结果重新选配置。
5. **观察权重变化。** 保存多特征线性回归及两组 Ridge 的权重表，列名与特征名对应；把三组权重画在同一张图中，采用分组柱状图或折线图均可。横轴为特征名，纵轴为标准化输入下的权重，图例注明模型和 `alpha`。观察权重的整体变化，不要求每一个权重都随 `alpha` 增大而严格变小。
6. **结合自己的结果解释。** 准备在组会中说明：增加特征后验证误差怎样变化；两组 Ridge 中为什么选择这一组；权重受到约束后，预测效果是否一定改善。根据实际结果回答即可，**不要求 Ridge 必须获胜，也不要求出现明显过拟合或达到指定分数。** 不另交书面分析报告。

本周必做结果控制为：**一份指标比较表、一份权重表、两张图**。统一使用 Python 脚本运行，表格保存为 CSV，图形直接导出为 PNG 图片，放在 `week03/results/` 中。图表中的模型名称、数据划分和参数设置要能与代码对应。

比较权重时，注意它们对应的是标准化后的输入。权重较大不直接等于这个特征“最重要”，更不能据此推断因果关系；多个特征之间可能包含相近的信息。本周能解释正负号与整体变化即可，不要求做特征重要性研究。

### 实践二：用一个小例子理解分类概率与指标

这一部分用于知识理解和组会讨论，约 20–30 分钟；**不要求训练分类模型，不要求提交新的代码、图表或书面答案。** 可以手算，也可以用几行代码核对。

二分类逻辑回归先将输入组合成一个分数，再通过 sigmoid 函数转换为类别 1 的概率估计：

```text
z = w1 × x1 + w2 × x2 + … + b
p = 1 / (1 + exp(-z))
```

知道 `z = 0` 时 `p = 0.5`，`z` 越大时 `p` 越接近 1 即可，不要求手算指数或推导训练公式。逻辑回归通常使用对数损失训练；分类准确率用于评价，不是把第二周的线性回归输出直接改名为概率。可查阅 [LogisticRegression 官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LogisticRegression.html)。

下面是人为构造的教学示例。设正常为 0、异常为 1，以异常为正类。表中的概率是假设已有模型给出的结果。

| 样本 | 真实类别 | 预测为异常的概率 |
|---|---:|---:|
| 1 | 1 | 0.90 |
| 2 | 0 | 0.70 |
| 3 | 1 | 0.60 |
| 4 | 1 | 0.40 |
| 5 | 0 | 0.30 |
| 6 | 0 | 0.10 |

先约定 `p >= 0.5` 时预测异常，否则预测正常。利用下面的说明练习：

1. 将六个概率转换成类别，找出哪些预测正确，哪些是误报、哪些是漏报。
2. 计算准确率、精确率和召回率。重点解释分母分别数的是哪些样本，F1 可按公式代入核对。
3. 如果只把阈值改为 0.3，哪些样本的预测类别改变？漏报和误报分别怎样变化？不用重新训练或搜索最优阈值。

```text
TP：真实异常，也预测异常
FP：真实正常，却预测异常（误报）
FN：真实异常，却预测正常（漏报）
TN：真实正常，也预测正常

准确率 Accuracy = (TP + TN) / 全部样本数
精确率 Precision = TP / (TP + FP)
召回率 Recall = TP / (TP + FN)
F1 = 2 × Precision × Recall / (Precision + Recall)
```

精确率关注“报出的异常有多少是真的”，召回率关注“实际异常有多少被找出来”。F1 是两者的调和平均，不是简单相加再除以 2。本例分母均不为零，暂不讨论零分母或多分类平均方式。指标定义可核对 [scikit-learn 分类评价说明](https://scikit-learn.org/stable/modules/model_evaluation.html#classification-metrics)。

思考：如果 100 条数据只有 5 条异常，全预测正常也能得到 95% 准确率，这是否说明异常检测做得好？能说清原因即可。
