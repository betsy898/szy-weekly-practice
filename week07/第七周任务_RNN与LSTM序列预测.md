## 二、知识点理解

### 1. 从 MLP 到 RNN：同一段历史可以怎样进入网络？

把过去 24 小时的油温作为 24 个输入特征，MLP 也可以预测下一小时；不同输入位置有各自对应的权重，因此它也能够利用历史顺序。RNN 则依次读取窗口，每一步把当前输入和此前状态结合，形成新的隐藏状态。

普通 RNN 可写成：

```text
h[k] = tanh(Wx × x[k] + Wh × h[k-1] + b)
```

这里使用列向量记法。`k` 表示窗口内的时间步，`h[k]` 是处理到这一步时形成的表示。同一层在不同时间步重复使用同一套 `Wx、Wh、b`；把计算画成一串节点，是同一个计算单元沿时间展开，不是每步新建一个独立网络。参考 [PyTorch RNN 说明](https://docs.pytorch.org/docs/stable/generated/torch.nn.RNN.html)。

这种共享让模型可以重复应用同一条状态更新规则。对固定结构的循环层，增加输入长度不会增加其参数数量，但会增加计算步骤；普通 RNN 的后一步依赖前一步状态，时间方向存在顺序依赖。

**理解提示：**如果用 MLP 和 RNN 处理同一个历史窗口，各自的参数在哪里共享？如果每个时间步都使用不同的权重，模型还能计算，但与原来的 RNN 有什么区别？不要只用“RNN 有记忆、MLP 没记忆”概括两者。

### 2. 最后才计算损失，前面的时间步怎样学习？

回顾第五周：损失只在网络输出处计算，但前面层的参数仍能得到梯度，因为输出依赖它们。RNN 中同样如此：末步状态依赖前一步状态，前一步又依赖更早的计算。反向传播沿着展开后的依赖关系计算梯度，这称为通过时间的反向传播，通常简称 BPTT。

共享参数在多个时间步被使用，最终梯度汇集这些使用位置对损失的影响，并不是只计算最后一次使用的贡献。梯度变小，意味着损失对相应变化不敏感，可能使依赖较早信息的学习变得困难；它不等同于状态数值变小或早期输入没有进入过前向计算。

跨越较多时间步时，链式法则包含多次局部导数相乘，梯度可能逐渐衰减，也可能放大。理解“依赖路径越长，学习信号要经过的变换越多”即可，不要求推导矩阵连乘。相关原理见 [RNN 训练困难的分析](https://arxiv.org/abs/1211.5063)。

**理解提示：**最后一个时间步有损失，是否意味着只有最后一步的计算受到训练？增加训练轮数、增大隐藏维数和改善梯度传递，解决的是同一件事吗？

### 3. LSTM 相比普通 RNN 增加了什么？

LSTM 仍然按时间递推、在各时间步共享参数。它在隐藏状态 `h` 之外增加了细胞状态 `c`，并通过门控管理信息的保留、写入和读出：

```text
c[k] = f[k] ⊙ c[k-1] + i[k] ⊙ g[k]
h[k] = o[k] ⊙ tanh(c[k])
```

`f、i、o` 分别为遗忘门、输入门和输出门，`g` 为候选写入内容，`⊙` 为对应位置相乘。细胞状态提供一条逐步保留与修改信息的路径，隐藏状态则是本步对外提供的表示，也参与下一步的门控计算。

三个门由当前输入和上一隐藏状态经过可学习变换，再经过 sigmoid 得到；门值在 0 与 1 之间，表示对各个状态分量的调节程度。候选内容经过 tanh，可以取正值或负值。门值通常是向量，不是给整个时间步统一指定的一个开关；门的参数通过最终任务损失学习，不需要人为提供“这一时刻应该忘记多少”的标签。参考 [LSTM 官方公式与接口](https://docs.pytorch.org/docs/stable/generated/torch.nn.LSTM.html)。

普通 RNN 的状态每步都经过完整的变换与非线性；LSTM 的细胞状态中有一条乘遗忘门后相加的直接传递路径，便于学习何时保留信息。这是理解它缓解长期依赖问题的关键，但并不保证记住全部历史或彻底消除梯度问题。

**理解提示：**如果只回答“LSTM 比 RNN 多三个门”，还没有解释这些部件为什么有用。请进一步说明：旧信息怎样留下，新信息怎样写入，保留的信息怎样参与当前输出，以及这些选择怎样通过训练形成。

### 4. 把历史汇总成一个表示：能够做到什么，又可能遗漏什么？

本周从最后一个时间步的隐藏状态生成预测。这相当于让模型在逐步读取过程中，把与任务有关的历史组织进一个固定维度的表示，再由输出层读取。

可以联系第四周的 PCA：两者都涉及表示变换，但本周隐藏表示通过预测损失学习，是随序列递推形成的非线性表示；PCA 学习保留输入方差的线性方向。隐藏维数也不必小于原窗口长度，因此不能简单把 LSTM 称为一种降维方法。

**理解提示：**同一个末步表示要兼顾多种历史信息时，哪些内容可能难以保留？模型结构允许早期输入影响结果，是否就证明训练后真的利用好了这段信息？后续学习其他序列模型时，我们还会继续讨论怎样保留、访问和组合不同位置的信息；本周不要求预习 Transformer 的具体结构。

使用 PyTorch 创建前向计算。将变换后的五维输入创建为可求导的独立张量，以便观察每个输入分量的梯度；本次求的是损失对这些已变换输入的导数，不是对原始数据预处理过程求导。

#### 2. 用共享参数完成五步前向

初始状态固定为 `h[0]=0`，三个标量参数初始值为 `wx=0.6、wh=0.5、b=0`，都启用梯度计算。五步始终使用这同一组三个参数：

```text
h[k] = tanh(wx × z[k] + wh × h[k-1] + b)，k = 1, …, 5
预测值 = 0.8 × h[5] + 0.1
损失 = (预测值 - z[6])²
```

输出变换中的 `0.8、0.1` 是固定常数，本小例子只观察三个循环参数的梯度。选择第 2 或第 3 步，用公式独立计算，再与程序核对。把状态传给下一步时保留其计算关系；转换为普通数值只用于记录，不要把记录用的数值重新接回前向计算。

每步记录当前输入、上一状态、输入项、历史项与新状态。再记录末端预测、目标和损失，说明隐藏状态与预测值由哪个操作连接。

**边做边想：从一个损失追到早期计算（对应 A4、B1）。**

1. 从损失出发，依次找到预测、`h[5]`、`h[4]`，再一直追到第一个输入。把这条依赖关系与 MLP 中“输出依赖前面各层”的关系对照：中间没有单独标签，是否就意味着中间计算无法影响最终误差？

图依据 [PyTorch 官方 LSTM 公式](https://docs.pytorch.org/docs/stable/generated/torch.nn.LSTM.html)重绘，与组会 A2 的参考图一致；A3 会提供官方公式，不要求背诵。

1. 先只看 `c[k] = f[k] ⊙ c[k-1] + i[k] ⊙ g[k]`：哪一项来自旧状态，哪一项是这一步写入的内容？只取一个分量，设旧状态为 `0.8`、遗忘门为 `0.9`、输入门为 `0.1`、候选内容为 `-0.5`，分别算保留量、写入量和新状态。这个小算例用于认识门的作用，不需要读取模型内部的真实门值。
2. 暂时把门值当成已知量：当 `f` 接近 1、`i` 接近 0 时，细胞状态会怎样变化？再看 `h[k] = o[k] ⊙ tanh(c[k])`，如果 `o` 很小，是当前读出被抑制，还是细胞状态一定被清空？沿图分开说清“保存”和“对外提供”，不要把 c、h 简单分成长期记忆和短期记忆。
3. 回到官方公式，找到产生 `i、f、o、g` 的四行。它们分别接收哪些输入？回忆 sigmoid 和 tanh 的输出范围，思考“写入多少”与“写入什么”为什么适合用不同的激活。输入门和遗忘门各有自己的参数，并不是要求两者相加等于 1 的两个比例。
4. 联系实践一的梯度连乘算例：只沿图中细胞状态的直接传递路径看，如果连续几步的遗忘门都接近 1，旧信息保留会有什么不同？这里帮助解释 LSTM 改善了哪条路径，不要求推导完整梯度，也不能据此认为整个网络的梯度只由遗忘门决定。

**再把图对应到代码输出（对应 B3）。**打开自己的形状记录，依次确认：

- `output` 的时间轴在哪？取最后一个位置后，还保留哪两个轴？
- `h_n` 最前面的轴表示什么？在本周单层、单向设置下，取出该层的最终隐藏状态，与 `output` 的末步表示怎样对应？
- `c_n` 与 `h_n` 形状相同，但从 c 到 h 还经过图中的哪些操作？如果把 c 直接送给原来的预测层，会绕过哪些计算？

能沿着“输入 → 状态更新 → 末步隐藏表示 → 线性预测”指出自己的实现即可，无需手写完整 LSTM。

#### 3. 明确窗口长度、隐藏维数和状态传递的边界

每个窗口从零隐藏状态和零细胞状态开始。可以省略 LSTM 初始状态参数，使用默认零状态，不把上一次调用返回的状态传给下一批。训练窗口可以打乱，窗口内部保持时间顺序，输入与标签始终配对。

结合两种配置和参数数量，区分：窗口长度决定本次输入多少时间步；隐藏维数决定每步状态的宽度；网络层数决定每步堆叠多少层循环计算。本周只训练一层，另外两种修改只作思考，不追加运行。

**边做边想：区分重复计算与改变模型（对应 B4、B5）。**

1. 在输入形状 `(B,L,1)` 和状态宽度 H 中，分别找到批量大小、窗口长度和隐藏维数。把 L 从 24 改成 48，是重复使用原有参数更多次，还是需要创建新的权重？把 H 从 16 改成 32 时，状态和门值会变宽，原有权重形状还能保持不变吗？用已有参数数量记录核对，不追加实验。
2. 画两条水平方向的时间链，再让下层每一步的输出进入上层同一步。这表示两层循环网络。对照只有一条链、时间步更多的情况，解释“多一层”和“多读几个时刻”为什么不是一回事。
3. 用三个时刻的小窗口代替 24 小时，写出相邻窗口 `[t1,t2,t3]` 和 `[t2,t3,t4]`。如果保留第一个窗口的末状态，再完整输入第二个窗口，实际读取顺序是什么？哪些时刻被重复读入，哪里发生了时间回退？再考虑训练样本被打乱后，传来的状态是否还属于相邻窗口。

最后在代码中分别找到模型参数和初始状态的设置：每个窗口把 h、c 置零时，有没有重新初始化权重？用这一区别解释，为什么重新开始处理一个窗口，并不等于把训练学到的规律清空。

#### 4. 复用训练流程，观察表示怎样通过预测任务学习

| 设置 | 两组共同要求 |
|---|---|
| 设备与类型 | CPU、`float32` |
| 优化器 | Adam，学习率 `0.001`，`weight_decay=0`，其余参数默认 |
| 损失 | 标准化目标上的 MSE |
| 批次 | `batch_size=128`、`drop_last=False`、`num_workers=0` |
| 训练轮数 | 每组完整训练 40 个 epoch |
| 随机性 | 每组创建模型前设置 `torch.manual_seed(42)`；每组 DataLoader 分别新建种子为 42 的随机生成器 |
| 顺序与对照 | 只打乱训练样本顺序；两组除隐藏维数外设置一致 |

每组独立创建模型和优化器，从未训练状态开始；不同宽度的参数形状不同，相同种子不等于相同初始参数。每组 DataLoader 独立初始化随机生成器，使训练样本顺序一致。

沿用第五周的清梯度、前向、损失、反向传播与参数更新流程。每轮结束后，在评价模式下关闭梯度记录，重新评价完整训练、验证集；按全部目标的误差平方和与总数计算 MSE。下一轮训练恢复训练模式。

每组保存验证 MSE 最小轮次的参数，完全相同时保留较早轮次；使用独立副本避免被后续训练覆盖。训练满 40 轮后恢复各自最佳参数，再比较原始尺度验证 RMSE，选择一组 LSTM，完全相同时选宽度 16。选择固定后，只对选定 LSTM 进行测试评价，不合并训练验证集重训。

**边做边想：没有门值标签，门怎样学习（对应 A3、A4、A6）。**

1. 沿自己的训练代码，从损失反向追到预测层、末步隐藏状态、细胞状态及门值，再追到产生门值的权重。哪些是需要优化器更新的参数，哪些只是这批输入计算出来的中间结果？联系实践一，解释为什么一个最终目标就能为内部计算提供学习信号。
2. 同一套门控权重在各时间步共享，是否意味着每一步的门值都相同？回到公式检查：除了权重，当前输入和上一隐藏状态有没有变化？区分“共享计算规则”和“每次得到相同结果”。
3. 回想 PCA 拟合时是否使用下一小时油温标签，再看本周损失是否使用这个标签。两种表示分别依据什么目标形成？末步隐藏向量的第 1 个分量，是否就代表窗口第 1 小时的油温？H 为 32 而窗口只有 24 步时，还能仅凭“变成隐藏向量”就把它叫作降维吗？

准备时优先讲清“预测误差通过依赖关系更新内部参数”。对每个隐藏分量的具体物理含义不作猜测，也不要求解释已训练模型的每个门值。

**边做边想：结果能支持什么结论（对应 A6、B6）。**

1. 最近值基线只使用一个观测。如果 LSTM 只学会利用最近两三步的变化，也有没有可能超过它？先用这个可能性检查“成绩更好，所以学会了长距离依赖”的推断是否充分。无论本次实际成绩如何，都可以讨论这个假设。
2. 只在纸上设计一个比较：分别使用最近 6 小时和完整 24 小时训练模型，并在**同一批验证目标**上比较。为了把差异尽量归因于历史范围，哪些训练条件应保持一致？较长历史带来收益可以支持什么判断，单次结果又可能受到什么影响？无需实际训练。
3. 另一个思路是固定模型和最近 6 小时，改动更早的输入。预测发生变化，首先说明模型对这些输入有反应；为什么还要结合预测误差，才能讨论这种利用是否有帮助？也要考虑改动后是否形成了不常见的输入。
