# 第七周：五步 RNN 与 ETTh1 LSTM 油温预测

两项实践可分别运行。数据沿用 `../week06/data/ETTh1.csv`，来源为 [ETDataset 官方仓库](https://github.com/zhouhaoyi/ETDataset/blob/main/ETT-small/ETTh1.csv)。需要保留 `week06` 目录，因为 `data.py` 直接复用第六周已核对的窗口、时间划分、最近值及滞后线性回归函数。实际环境：Python 3.13.5、PyTorch 2.14.1+cpu；其他版本见 `requirements.txt`。

进入 `week07` 后运行：

```powershell
python -m pip install -r requirements.txt
python run_rnn.py
python run_lstm.py
```

`run_rnn.py` 和 `run_lstm.py` 分别组织实验；`data.py` 为两个入口准备数据并复用第六周逻辑；`models.py` 实现五步 RNN、LSTM 前向及逐批训练和最佳轮次恢复；`evaluation.py` 负责无参数更新的整集评价、原始尺度预测和指标计算；`reporting.py` 保存结果和绘图。关键接口 `prepare_series` 同时返回原始时间窗和张量、训练时段统计量，因此基线与 LSTM 能使用同一批目标时刻，而各自采用指定的输入变换。导入这些组件不会启动训练。

## 实践一：五步共享参数 RNN

原始前六小时 `OT` 依次为约 `[30.531, 27.787, 27.787, 25.044, 21.948, 21.174]`。按 `(OT-30.531)/10` 变换，前五个值作为独立可求导输入，第六个是目标。`models.py` 的循环每步使用同一 `wx=0.6, wh=0.5, b=0`，状态更新为 `tanh(wx*z + wh*h_prev + b)`；末状态经 `0.8*h5+0.1` 得到预测。

可手工核对第 2 步：`z2≈−0.2744`，`h1=0`，故 `h2=tanh(0.6×(−0.2744)+0.5×0)≈−0.163168`，与 `rnn_trace.csv` 一致。原顺序的末端预测为 `−0.396435`，目标为 `−0.935700`，平方损失为 `0.290806`。仅对这一次损失反传，三个共享参数的梯度分别为 `wx=−0.616943`、`wh=−0.293199`、`b=0.926310`；五个输入梯度依次为 `[0.014993, 0.029987, 0.061613, 0.130850, 0.318343]`。第一个输入经 `h1→h2→h3→h4→h5→预测→损失` 参与计算；梯度在时间步间汇集到同一个共享参数。这个五步例子不能证明长序列必然出现梯度消失。

重排顺序 `[1,4,3,2,5]` 后，第 2 步状态由 `−0.163168` 变成 `−0.317820`，末端预测变成 `−0.368081`。首尾输入相同，结果仍不同，因为每一步使用的上一状态已改变。对照组只做前向，没有梯度记录，也不代表真实设备运行顺序。`results/rnn_trace.csv` 的每行对应一组序列中的一步，`source_index` 是原 CSV 零基下标；原顺序的 `input_grad` 来自这一次反传，重排组留空。

## 实践二：24 小时窗口与 LSTM

使用前 14,400 小时的 `OT`，先构造 24 小时历史预测下一小时，再按目标时间划分，训练/验证/测试目标数为 8616/2880/2880。训练时段原始 OT 每个时刻只计一次，得到 `μ=17.128262`、总体 `σ=9.176491`（`ddof=0`）；输入与目标均按此标准化。张量输入形状 `(N,24,1)`，目标 `(N,1)`。第一条验证样本的窗口结束于 2017-06-25 23:00，最近 OT 为 20.752，目标为 2017-06-26 00:00 的 20.963。验证、测试期间每次预测可使用之前已实际观测的 OT，模型参数保持不变。

两组均为单层、单向 LSTM，`input_size=1`、`batch_first=True`、无 dropout 和投影，取 `output[:,−1,:]` 接线性层得到一个预测。128 条样本前向时：

| 隐藏宽度 | 输入 | 每步输出 | `h_n` / `c_n` | 预测 | 参数量 |
|---|---|---|---|---|---:|
| 16 | `(128,24,1)` | `(128,24,16)` | `(1,128,16)` | `(128,1)` | 1,233 |
| 32 | `(128,24,1)` | `(128,24,32)` | `(1,128,32)` | `(128,1)` | 4,513 |

`output` 第二维是 24 个时间步；本单层单向设置中，末步输出等于 `h_n[-1]`。`c_n` 与 `h_n` 形状相同，但细胞状态经输出门和 `tanh` 形成对外隐藏状态，预测层读取的是后者。每个窗口默认从零状态开始，权重在不同窗口间保留并由训练更新；窗口长度不会新增循环权重，隐藏宽度会改变参数数量。

两组各训练 40 个 epoch，CPU、float32、Adam 学习率 0.001、batch size 128。每组独立建模并重置种子 42，各自的 DataLoader 也使用种子 42；每轮对完整训练和验证目标重算标准化尺度 MSE，恢复验证 MSE 最低的轮次。宽度 16 最佳于第 38 轮，宽度 32 最佳于第 39 轮。两组验证 RMSE（原始油温尺度）分别为 **0.914489** 和 **0.914153**，故选定 **`lstm_h32`**。基线沿用第六周的同一时间划分与原始目标：最近值验证 RMSE 0.925271，滞后线性回归为 0.910183。选定 LSTM 的测试 RMSE 为 0.609383；测试只评价两种基线和选定 LSTM。

具体例子：2017-06-26 03:00 的目标原表下标为 8643，输入是此前 24 个真实小时的 OT。窗口按时间从旧到新输入 LSTM，各步更新细胞和隐藏状态，末步隐藏表示送入线性层；还原到原尺度后，`lstm_h32` 预测 **20.064**，实测 **19.908**，误差约 +0.156。同一时刻最近值预测 20.119，滞后线性回归预测 20.140。LSTM 在该点更接近实测，但完整验证集并未超过线性基线。现有结果只说明本次配置的预测表现；不能据此断言模型学到了 24 小时前的信息、每个隐藏分量有固定物理含义，或更长历史一定有效。若要检验早期信息的帮助，应在相同目标时刻及训练条件下比较 6 小时与 24 小时窗口。

## 输出

- `results/rnn_trace.csv`：两种输入顺序各五步的输入项、历史项、状态及原顺序输入梯度。
- `results/history.csv`：两组各 40 轮的完整训练/验证 MSE，尺度为标准化 OT。
- `results/metrics.csv`：基线与两个 LSTM 的训练/验证指标，以及基线和选定 LSTM 的测试指标；均为原始 OT 尺度。
- `results/predictions.csv`：所有规定模型、时段、目标下标与时间的逐行真实值和预测值；由这些行重算 MAE/RMSE 与汇总表核对。
- `results/loss_curves.png`：两种宽度的整集训练/验证 MSE 与各自最佳轮次。
- `results/validation_predictions.png`：验证首周 168 小时真实 OT、最近值、滞后线性回归、选定 LSTM 的对齐曲线。
- `results/lstm_best.pt` 与 `results/lstm_best_metadata.json`：选定 LSTM 的最佳参数及隐藏维数、轮次、训练 OT 均值/标准差、窗口长度和随机种子。
